The dependency source cache is split into two release assets. In Command
Prompt, join them in order to restore the original ZIP:

copy /b ffmpeg-dependency-sources.zip.001+ffmpeg-dependency-sources.zip.002 ffmpeg-dependency-sources.zip

Extract the ZIP to obtain cache.tar.gz. SHA256SUMS.txt on the source release page
contains checksums for the archives, including both parts and the joined ZIP.
